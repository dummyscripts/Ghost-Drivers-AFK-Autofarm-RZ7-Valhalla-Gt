## Questions

### What is the Dummy Scripts Ghost Drivers script?

It is a Ghost Drivers autofarm demo with a compact driving panel for Valhalla GT and Wulfbrecht RZ7. It provides speed presets, a custom target MPH and continuous ON/OFF driving using physical route assistance.

### How do I get a free Ghost Drivers key?

Select Get free key on this page or Get key in the script. Complete the LootLabs tasks in the same browser, copy the issued key, and paste it into the script to unlock. No purchase is required; LootLabs tasks are required.

### How long does a key last, and when does it bind?

A key lasts 72 hours from issuance. It stays unbound until its first successful use in the script, then locks to that Roblox account. Getting a key in your browser does not bind it.

### Which cars and speed options are supported?

The demo includes Valhalla GT and Wulfbrecht RZ7 profiles. Choose Cruise, Fast, Max or a custom target in dashboard MPH. Speed can be changed while ON. Traffic and bends can require lower speeds; Max is a target cap, not a guaranteed attained speed.

### How do I stop, hide or update the script?

Switch OFF or press F8 to stop. Right Shift hides or shows the panel. For an update, switch OFF, wait for the car to stop and cleanup to finish, then execute the same loader again and unlock.

### Does it run forever or guarantee earnings?

Continuous mode has no set run timer and retries recoverable interruptions while ON. Disconnections require rejoining and executing again. Idle protection and driving access depend on executor capabilities. No crash-free runtime, earnings rate, or top-speed result is guaranteed.

### Does it work on Windows and Opiumware?

The interface and unlock flow require compatible executor APIs, including HTTP POST for keys and access to the car controls for driving. Windows and Opiumware have not completed live qualification. A visible GUI alone does not prove driving compatibility.
